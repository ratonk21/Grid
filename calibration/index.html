01 · Objetivo y alcance01 · Purpose and scope

Qué estamos verificandoWhat we are checking

El nodo UbiCell UG lleva dentro un medidor de energía: registra cuánta electricidad (Wh) consume la luminaria. Este procedimiento comprueba que ese medidor mide con la exactitud que exige la norma. El resultado es un solo número: un porcentaje de error que debe quedar dentro de un límite.

The UbiCell UG node has an energy meter inside: it records how much electricity (Wh) the luminaire uses. This procedure checks that the meter measures within the accuracy the standard requires. The result is a single number: an error percentage that must stay within a limit.

  • Para quién: personal de laboratorio o terreno con acceso a una estación de prueba de medidores. Escrito para que también lo siga alguien no técnico.
  • Who for: lab or field staff with access to a meter test station. Written so a non-technical reader can follow along too.
  • Este nodo: Current Class 10 y Accuracy Class 1.00. Esos dos datos definen todo el resto.
  • This node: Current Class 10 and Accuracy Class 1.00. Those two facts define everything else.
Por qué importaWhy it matters

El medidor del nodo registra energía. Si mide de más, se sobrestima el consumo; si mide de menos, hay energía que "no aparece". La norma fija cuánto error se tolera para que el registro sea confiable.

The node meter records energy. If it reads high, consumption is overstated; if it reads low, energy "goes missing". The standard sets how much error is tolerable so the record can be trusted.

02 · Antes de partir02 · Before you start

SeguridadSafety

La prueba usa tensión (120 V) y corriente reales. Trátala como trabajo eléctrico energizado.

The test uses real voltage (120 V) and current. Treat it as energized electrical work.

  • Solo personal capacitado; estación con sus protecciones operativas.
  • Trained personnel only; test station with its protections working.
  • Desenergizar siempre antes de montar o desmontar el nodo en la base.
  • Always de-energize before mounting or removing the node from the socket.
  • No tocar terminales ni la base con la fuente activa ("Drive ON").
  • Do not touch terminals or the socket with the source active ("Drive ON").
  • Banco firme, sin vibración, y área despejada.
  • Firm bench, free of vibration, and a clear work area.
RecuerdaRemember

Ante cualquier duda de seguridad, detén el ensayo y consulta antes de energizar.

If you have any safety doubt, stop the test and check before energizing.

03 · Fundamento03 · Background

Cómo funciona la normaHow the standard works

Cómo funcionan las normas ANSI C12.20 y 12.1:

  • Hay distintas pruebas (desempeño de carga, variación de factor de potencia, variación de frecuencia y variación de tensión).
  • Cada una de estas pruebas tiene una condición de referencia. Para Accuracy Class 1.0, la condición de referencia debe quedar dentro de ±0.4% de error de exactitud.
  • Cada condición adicional debe quedar dentro de la desviación aceptable definida en cada tabla (para clase de exactitud 1.0, la mayoría tiene una desviación permitida cercana a ±1.0%).
  • También existen tolerancias admisibles para el equipo de prueba, que influyen en la exactitud global.

How ANSI C12.20 & 12.1 standards work:

  • There are different tests (load performance, power factor variation, frequency variation and voltage variation).
  • For each of these tests, there is a reference condition. For Accuracy Class 1.0, the reference condition must be within ±0.4% accuracy error.
  • Each additional condition must be within whatever acceptable deviation from the reference is defined in each table (for accuracy class 1.0, most of the conditions have an allowable deviation close to ±1.0%).
  • There are also allowable tolerances for the test equipment, which factor into overall accuracy.
04 · Detalles de la norma04 · Standard details

Detalles de la norma: tolerancias, condiciones y clases de corrienteStandard details: tolerances, conditions and current classes

4.6.1  Tolerances4.6.1  Tolerances ANSI C12.20

Debido a posibles errores en las observaciones y en el equipo de prueba empleado, a los límites de desviación porcentual especificados se les debe aplicar una tolerancia para cualquier condición de prueba que implique determinar la exactitud del medidor. Un medidor se considera dentro de los límites permitidos si la desviación medida no excede la desviación máxima especificada respecto del desempeño de referencia por más de 0.1% o por un décimo de la desviación máxima, lo que sea menor.

Por ejemplo: si se establece la condición de referencia y la desviación permitida respecto de la condición de referencia es 0.2%, entonces 0.22% es aceptable por la tolerancia de un décimo de la desviación máxima.

Because of possible errors in observations and in the test equipment employed, a tolerance should be applied to the specified limits of percent deviation for any test condition involving a determination of the accuracy of the meter. A meter shall be considered to be within the allowable limits if the measured deviation does not exceed the specified maximum deviation from reference performance by 0.1% or by one-tenth of the maximum deviation, whichever is lower.

For example: If the reference condition is made, and the allowable deviation from the reference condition is 0.2%, then 0.22% is acceptable because of the one-tenth of the maximum deviation tolerance.

4.7.1  Test conditions4.7.1  Test conditions ANSI C12.20

El medidor se monta sobre un soporte libre de vibración. Todas las pruebas de corriente alterna se realizan en un circuito alimentado por una fuente sinusoidal, con una distorsión armónica total no mayor a 1% en corriente y tensión. Para medidores con dispositivos auxiliares alimentados línea a línea, el medidor se prueba energizando individualmente los circuitos de tensión y corriente para alimentar el dispositivo auxiliar como lo haría en operación normal.

Todas las pruebas, salvo que se indique lo contrario en pruebas específicas, se hacen a 23°C ±2°C; tensión nominal ±1%; frecuencia nominal ±1 Hz; corriente de prueba ±1%; y factor de potencia unitario (0° ±2°). El medidor se estabiliza a temperatura ambiente antes de las pruebas de desempeño. El desempeño del medidor bajo las condiciones anteriores debe ser tan cercano a cero error como sea práctico y en ningún caso debe exceder ±0.4% de error para clase de exactitud 1.0, 0.2% para clase 0.5, 0.1% para clase 0.2, o 0.05% para clase 0.1. El medidor no se reajusta durante la prueba. Este requisito solo aplica a la aprobación de tipo y no está previsto para la aceptación en recepción ni para la verificación en servicio.

The meter shall be mounted on a support that is free of vibration. All alternating-current tests shall be conducted on a circuit supplied by a sine-wave source, with a total harmonic distortion no greater than 1% on current and voltage. For meters with auxiliary devices powered line-to-line, the meter shall be tested with the voltage and current circuits individually energized to power the auxiliary device as it would be in normal operation.

All tests, unless otherwise indicated in specific tests, shall be made at 23°C ±2°C; rated voltage ±1%; rated frequency ±1 Hz; test amperes ±1%; and unity power factor (0° ±2°). The meter shall be stabilized at ambient temperature before performance tests are made. The meter performance under the test conditions above shall be as close as practical to zero error and in no case shall exceed ±0.4% error for accuracy class 1.0, 0.2% error for accuracy class 0.5, 0.1% error for accuracy class 0.2, or 0.05% error for accuracy class 0.1. The meter shall not be readjusted for the duration of the testing. This requirement only applies to type testing approval and is not intended for incoming acceptance testing or in-service testing.

06 · Condición de prueba06 · Test condition

Recomendación de condición de prueba y ajustes DTS-2990Test condition recommendation and DTS-2990 settings

Con estas especificaciones en mente, nuestra recomendación es ensayar en nuestra referencia: 120 V, 2.5 A, 60 Hz y 1 PF (0 grados de desfase). Para cumplir con Accuracy Class 1.0, debemos estar dentro de ±0.4%.

La salida real de pulsos del medidor es 1 Wh por pulso, así que la estación de prueba debe reflejarlo para medir bien la exactitud. En la DTS-2990 esto se logra fijando el parámetro «Kt» en 1.

With these specifications in mind, our recommendation is to test at our reference: 120V, 2.5A, 60 Hz and 1 PF (0 degrees phase shift). To comply with Accuracy Class 1.0, we must be within ±0.4%.

Our meter's actual pulse output is 1 Wh per pulse, so the test station must reflect this to measure accuracy properly. On the DTS-2990, this is achieved by setting the parameter "Kt" to 1.

ConstantesConstants

Constantes que se verifican: Kh = 1 Wh/pulso y Kt = 1 (deben ser iguales). Con estas constantes, la estación compara los pulsos del nodo contra la energía suministrada y confirma que lo que el nodo registra corresponde a la energía realmente entregada.

Constants being verified: Kh = 1 Wh/pulse and Kt = 1 (must be equal). With these constants, the station compares the node’s pulses against the energy supplied and confirms that what the node registers matches the energy actually delivered.

Aclaración ±0.4% vs 1%Note on ±0.4% vs 1%

La estación se puede fijar con umbral operativo de 1%, pero el criterio normativo de la condición de referencia es más estricto: ±0.4%. Usa el ±0.4% como criterio de aprobación de la referencia.

The station can be set with a 1% operating threshold, but the normative criterion for the reference condition is stricter: ±0.4%. Use ±0.4% as the pass criterion for the reference.

07 · Sensor infrarrojo07 · Infrared sensor

Ubicación del sensor infrarrojoIR sensor location

ImportanteImportant

La unidad debe cubrirse en la parte de arriba para que el relé interno cierre el circuito entre la línea y la carga, antes de poder realizar una prueba de medida.

The unit top must be covered so the internal relay closes the path between line and load before an accuracy test can be performed.

Por qué hay que taparlaWhy it must be covered

El nodo tiene un relé interno que solo cierra el circuito entre línea y carga cuando "cree" que es de noche. Si el relé está abierto, no pasa corriente por el medidor. Al tapar la fotocelda simulamos oscuridad → el relé cierra → la corriente fluye → se puede medir.

The node has an internal relay that only closes the circuit between line and load when it "thinks" it is night. If the relay is open, no current flows through the meter. Covering the photocell simulates darkness → the relay closes → current flows → it can be measured.

  • Reference (120 V / 2.5 A / 60 Hz / 1.00 PF): |error| ≤ 0.4%.

Regla rápidaQuick rule

Si en la referencia el banco muestra un error dentro de ±0.4%, con Kt = 1, fotocelda tapada y captador alineado, el nodo aprueba.

If at the reference the station shows an error within ±0.4%, with Kt = 1, photocell covered and pickup aligned, the node passes.

10 · Solución de problemas10 · Troubleshooting

Solución de problemasTroubleshooting

  • Error absurdo: revisa Kt = Kh = 1, captador alineado y parte superior tapada (relé cerrado).
  • Absurd error: check Kt = Kh = 1, pickup aligned and top covered (relay closed).
  • No cuenta pulsos: lo más común, fotocelda sin tapar o captador mal alineado.
  • No pulses: most commonly, photocell uncovered or pickup misaligned.
  • Inestable: THD > 1%, temperatura fuera de 23 °C ± 2 °C, o vibración.
  • Unstable: THD > 1%, temperature outside 23 °C ± 2 °C, or vibration.
  • Criterio: usa ±0.4% para la referencia y la Tabla 12 para el resto.
  • Criterion: use ±0.4% for the reference and Table 12 for the rest.
